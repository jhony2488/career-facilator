# Tutorial 01 — Local install from the repository

This mode is ideal if you plan to edit the code or want to keep data inside the project folder.

## Requirements

- Node.js **v22** or later
- git
- npm

Check:

```powershell
node --version   # should print v22.x.x
npm --version
```

## Step-by-step

1. Clone the repository and enter the folder:

```powershell
git clone https://github.com/jhony2488/career-facilitator-ts.git
cd career-facilitator-ts
```

2. Install dependencies:

```powershell
npm install
```

3. Copy the configuration template:

```powershell
cp .env.example .env
```

4. Keep data inside the project (already set in the example `.env`):

```dotenv
CAREER_HOME=.
```

5. Test the CLI:

```powershell
npm run cli -- version
npm run cli -- status
```

6. Open the interactive shell:

```powershell
npm run cli
```

The `career>` prompt appears. Type `help` to see the commands.

## Where data lives

With `CAREER_HOME=.` everything stays inside the repo:

- `storage/jobs.sqlite` — jobs and applications
- `storage/profile_inbox/` — pending resume PDFs
- `storage/profile.draft.md` — draft generated by `import --pdf`
- `src/config/profile.master.md` — active approved profile
- `src/config/profile.master.json` — compiled profile used by the AI

## Useful dev commands

```powershell
npm run dev              # same as `npm run cli`
npm run cli -- status    # database summary
npm run cli -- import --pdf cv.pdf
npm run cli -- review
npm run cli -- approve
npm run test:unit        # fast suite
npm run test:integration # real SQLite
npx tsc --noEmit         # typecheck
```
