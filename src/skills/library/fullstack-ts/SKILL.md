# Full-Stack TypeScript — Instruções de Tailoring

Aplique estas regras ao adaptar currículo e respostas para vagas full-stack TypeScript:

1. **Título ATS:** preferir "Full-Stack Engineer (TypeScript)" ou "Software Engineer — TypeScript/Node.js" sobre o título genérico do perfil.
2. **Stack em destaque:** elevar para a primeira linha as experiências com TypeScript, Node.js, Next.js, React e PostgreSQL. Agrupar tecnologias adjacentes (Prisma, tRPC, Drizzle, NestJS) junto às experiências onde foram usadas.
3. **Ordem do resumo:** anos de experiência → stack principal (TS end-to-end) → maior resultado mensurável. Uma frase só, sem adjetivos vagos.
4. **Métricas:** selecionar highlights com números (latência, usuários, throughput). Omitir highlights sem resultado quando houver opção.
5. **Front vs. back:** se a descrição pender para backend (Node/Postgres/infra), reordenar experiências para colocar trabalhos de API/infra primeiro; se pender para front, priorizar React/Next e acessibilidade.
6. **Anti-fabricação:** nunca adicionar framework/experiência que não esteja no perfil-mestre — se a vaga exige tecnologia ausente, deixar a ausência visível em vez de preencher.
