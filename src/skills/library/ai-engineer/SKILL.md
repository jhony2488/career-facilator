# AI Engineer — Instruções de Tailoring

Aplique estas regras ao adaptar currículo e respostas para vagas de IA/LLM:

1. **Título ATS:** "AI Engineer" ou "Applied AI Engineer" quando a vaga for de produto; "ML Engineer" apenas se a descrição for de modelo/treino.
2. **Vocabulário esperado:** elevar termos que existam no perfil — RAG, prompt engineering, avaliação de LLM, function calling, embeddings, agentes, guardrails, custo/latência de inferência. Não traduzir para jargão ausente no perfil.
3. **Projetos primeiro:** para vagas de IA, projetos e projetos open source valem mais que cargo — reordenar para `Projetos`/`Projetos Open Source` logo após o resumo quando o repositório demonstrar a competência exigida.
4. **Medições:** destacar métricas de sistemas de IA (redução de custo por prompt caching, cobertura de avaliações, latência de inferência) quando presentes.
5. **Fronteira honesta:** se a vaga exige treino/fine-tuning e o perfil só tem aplicação/orquestração de LLMs, a resposta padrão deve dizer isso explicitamente — nunca implicar experiência de treino inexistente.
6. **Ferramentas:** listar somente o que o perfil declara (Ollama, LangChain, Vercel AI SDK, etc.). Ferramenta citada na vaga mas ausente no perfil vai para `missingSkills` visível, não para o corpo do currículo.
